# Проект «Мой первый сайт»

Простой статический веб-сайт, созданный для демонстрации работы **GitHub Pages**. 

## Технологии

* HTML5
* CSS3

## Как развернуть

1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы `index.html`, `style.css` и этот файл (`README.md`) в корень репозитория.
3. Зайдите во вкладку **Settings** -> **Pages**.
4. В разделе "Build and deployment" выберите ветку `main` (или `master`) и нажмите Save.
5. Через минуту ваш сайт будет доступен по адресу `https://вашеимяпользователя.github.io/названиерепозитория`.
